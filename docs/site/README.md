# Static landing page

Plain HTML/CSS, with a screenshot of the actual web client using controlled example content.
No tracking, remote scripts, forms or API keys. The screenshot is illustrative, not efficacy evidence.

Publication is prepared in `.github/workflows/pages.yml` with **manual dispatch only**. After the
changes are reviewed and pushed, enable GitHub Pages with GitHub Actions as the source, then run
**Publish landing page**. No deployment was performed while preparing these files.

The landing page links to the repository setup guide. It does not host the tutor or proxy provider calls.
