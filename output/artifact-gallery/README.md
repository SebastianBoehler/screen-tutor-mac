# ScreenTutor artifact screenshots

Actual captures of the running React client on 18 November 2026. Example teaching content was placed in an isolated incognito workspace; no private course material, API key or live provider output was used.

Open index.html to browse the gallery. Each type has an artifact crop and a full application screenshot.

- math: rendered equations and a written response.
- choice: a prediction selected using the radio control.
- mechanism: a static concept-flow diagram.
- hint: a cue opened using the actual hint control.
- recall: a worked answer opened using the actual reveal control.
- code: a Markdown table and code walkthrough, with a written-response field.

These captures predate the compiled interactive models and compact artifact previews now in the client.
They show supported visual and interaction states at capture time, not educational efficacy.
The current interactive models are documented in ../../web/README.md.
